# v0.1 — harness

Goal: `pip install velocia` + Docker runs a TPC-H-derived experiment and a TeraSort job on vanilla Spark and one accelerated engine, with medians, CIs, correctness and custom measures, ending in an offline HTML report. Exit: every v0.1 box in `03-spec.md §11`.

Hours are your hours (review, testing, debugging). Spec references: `03` = functional spec, `04` = interfaces, `05` = quality, `06` = design.
